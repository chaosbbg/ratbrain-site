rat_brain v0.3 — place cells + striatal actor/critic + dopamine, no skull
substrate: browser · body: virtual only · status: ● running below

A rat's brain is a control system for a rat. Strip the body away entirely and you don't free it — you put it in total sensory deprivation. So this one was given a fake body instead: a grid, a hunger clock, some food, some hazards. It is alive on this page right now, and it can starve.

[02] PREMISE

    

    
Every region in a rat's brain earns its keep by turning sensation into movement. Whiskers into barrel cortex, odour into the olfactory bulb, hunger into the hypothalamus, all of it funnelled through the basal ganglia into an action. A brain with no input and no output isn't liberated; in real tissue, deprived cortex destabilises rather than rests.

    
So the design question was never whether to have a body. It was what stands in for one. Here it's a narrow contract: a sensory vector in, one of four actions out, and a scalar reward. Whatever sits on the other side — this maze, a game, a data stream — the brain can't tell, and doesn't need to.

    
Press unplug body above and you get the control condition: the same weights, the same neurons, fed nothing but noise. It doesn't die. It doesn't think. It just idles, with no trend in any direction, which is the closest thing this project has to a finding.

  


  

    
[03] ANATOMY

    

    

    
Fidelity is deliberately uneven. The hippocampal–striatal–dopaminergic loop is modelled in earnest because it's the best-understood learning circuit in rodent neuroscience. The rest are named stubs, so the gaps stay visible.

The right-hand rail is the loop that makes the whole thing a brain rather than a classifier: action changes the body, the body changes the next sensory vector. Dopamine carries reward prediction error into the basal ganglia, where it decides which synapses survive.
